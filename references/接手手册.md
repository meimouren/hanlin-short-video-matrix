# 接手手册

## 开始时先定位

录下题材、目标家长问题、输入文件、账号和平台、是否真人出镜、要交稿还是交成片。只给题目时，可先拆知识点、查来源和语料、出不依赖私有素材的分镜。先检查现成项目脚本和对应专项技能。用本仓库试跑时读取下面的 AIME 路线。制作新内容时从实际工作区根目录执行各路线，根目录有 `矩阵制作.py`、`制作工具/` 和 `短视频风格预览.html`。

| 环境 | 能直接完成 | 需要补齐的输入 |
|---|---|---|
| 只有技能包 | AIME 六幕、配乐、首帧、独立封面与字幕复现，核对规则、选风格和编写新方案 | 新主题事实、可用的当期资料和配音 |
| 有矩阵工作区 | 录播转写、原声拆条、老师稿、矩阵编码和本地验片 | 本期原片或通知、账号目标、授权素材。云配音需运行环境已有凭证 |

主线程记录每项的实际输入、已完成产物和验收结论。项目内用 `hanlin_research` 核事实、`hanlin_writer` 写稿、`hanlin_visual` 做视觉、`hanlin_editor` 做转写或成片、`hanlin_qa` 独立验收。只有一个 AI 时按同一交接顺序工作。

## A. 讲座或老师 IP 录播

矩阵工作区有 `hanlin-lecture-clips` 时先调用该专项技能，按它的案例复用小圆窗、图解、配乐和验片。首次接手可从工作区的《录播切片工作流·三条实战》对照原片与交付。

1. 在工作区执行下列命令。输出 `原片转写.json`。从其中的片段及逐词时间整理成可通读的带时间码文案。转写前确认原片、模型与可用空间。短段试听校对中英赛事名、老师名、数字和术语。视频没课件时从原话画出概念和关系，讲者未说明的条件保留为未知。

```powershell
python -X utf8 制作工具/录播转写.py "素材库/原片.mp4" "新批次/录播" --术语 "于老师,AMC,AIME,USABO"
```

2. 先通读全文，理解每个问题的结论、前提、证据及推理顺序，再按语义回看画面。列 3–5 条候选，写家长问题、独立答案、必留条件、源起止秒、起止原话、可见画面、图解设想。重复重录先听再删。于老师是优先剪辑对象，身份以声音和真实原片核实。
3. 选一题剪净原声。选题单 `sha256` 复制转写文件的同名字段，`作品` 每行写 `标题`、`封面`（分行数组）、`账号`、`平台`、`片段`；片段写 `起`、`止`（源绝对秒数），按需加 `字幕`（每项 [起, 止, 校订短句]）和 `取景`（归一化 [左, 上, 宽, 高]）。必要时加 `设计封面`、`正文底图` 和 `原片画框`，详见[工作流原有字段](录播与热点三条工作流.md#录播--短视频)。

```powershell
python -X utf8 制作工具/录播拆条.py "新批次/录播/原片转写.json" "新批次/录播/选题单.json" "新批次/原声净片"
```

4. `录播拆条.py` 的粗剪用静态底图和矩形原片画框校时。净片通过后做内容主导的分镜和独立封面。有动态圆窗需求可从 `工作流样片/10月13日直播于老师/特长与时间·动态圆窗版/制作记录/` 复用 `输出知识动画.py` 和 `合成动态圆窗.py` 的场景与合成逻辑，按新题改原片、图形、裁切和锚点。老师用小圆窗保留语气、口型和身份，图解占主体。自行补的题或示意标为「图解举例」。画面给到真正的比较、分支、因果和步骤；校园、人物或材料随场景排版变动。口播原声不可改成改变原判断的拼接。
5. 用 `python -X utf8 制作工具/录播配乐.py 定稿画面.mp4 新配乐版.mp4 --speech 同轴原声合成.mp4 --style plucked` 混音，可换 `mallet` 或 `piano-beat`。只换配乐时用未混音乐的同轴原声。验收时逐句对照原话和成片。让手机画面同时读清条件、图解、字幕，检查圆窗、口型、文案尾句与配乐。可参考工作区 `工作流样片/录播切片工作流·三条实战.html` 和 `三条样片·封面与配乐.html`。

**实例做法**　「竞赛、夏校、科研，先选哪个」先锁定原话涉及的特长和可用时间，再设计两条判断轴，分支上的答案必须能在原声定位。「USABO 怎么备赛」把老师原话里的已学内容和适用阶段画成路线，画面动作跟随说到的阶段。交付样片保留各自独立封面和轻配乐。

## B. 热点交老师录制

1. 记录每个事实的来源、日期、地区、适用对象、状态和核实时间。有相互冲突的渠道通知时逐渠道保留口径；把预计、暂定、待核对应到字段。每条只回答一个家长问题。
2. 用事件名、别名、常见 ASR 错写和动作检索标题、笔记正文、口播全文。通过 `--全量` 保留所有相关命中。对每个可用素材写开场前提、答案顺序、数字和断句、素材号及时间码。记录排除理由和待转写候选，补转后继续审。仅浏览笔记标题不能证明有完整口播。

```powershell
python -X utf8 "小红书账号归档/口播语料与风格库/更新口播库.py" --关键词 AMC AIME 考点 --全量
python -X utf8 矩阵制作.py 新建 "新热点批次"
python -X utf8 矩阵制作.py 老师录制稿 "新热点批次" 01
```

在新建和导出之间填写 `本期内容.json`、`新版分镜.json`、`批次索引.json`。四段稿逐段一致，动作和字幕各自挂到对应句。详见[批次字段](制作接口.md)。工作区命令只接受一级批次名和真实账号编号；渲染前去掉模板带来的旧主题素材或字段。

3. 用顾问跟一位家长说话的节奏，开头说清「哪场晋级到哪场、这一步要做什么」。断句标 `/` 短停、`//` 长停；英文逐字母或全称按实际读法写在提词提示里。例「孩子从 A-M-C 十或十二晋级到 A-I-M-E 了，/ 这次去哪儿考？// 您先翻一下当时报名的记录。」A-I-M-E 逐个字母。数字和单位连读，关键口径用原通知核实。回收老师实录后按 A 路线重新转写和对齐。

## C. 热点直接配音和纯动画

1. 沿用 B 的事实表和顾问稿。按 `说到哪句 / 观众要懂什么 / 哪个形状、比例、顺序或状态变化 / 验收帧` 写分镜。没有真人实录的热点，正文和封面都选无人物。IP 只作为可选授权音色。
2. 先合成开场问句、提醒、英文缩写和数字三类试听，至少准备自然、带轻提醒的不同读法，听清尾音再定。记录模型和实际选中音色。只在确认授权音色和可用接口时合成 IP 声。百炼 AIME 已认可样片用系统男声。按语义段合成，保留干声、字级或可核对的语义段时间。提速从干声开始，保音高，所有停顿、字幕和画面锚点用同一时间变换。背景音乐原速，轻快且压在人声下，至少对比两种可靠配乐。
3. 双渠道先确定统一的字段、名称、色彩和时间刻度。AIME 六幕依次为开场、考点、时段、该渠道独有的作答规则、费用、汇总。两个收场时刻用同轴不同终点，预计或待定放在对应数字旁，图例和文字同时保留。替换字段见[选风格与找素材](选风格与找素材.md)。
4. 普通矩阵热点在真实工作区填写批次后跑一条。

```powershell
python -X utf8 矩阵制作.py 配音 "新热点批次" 01
python -X utf8 矩阵制作.py 分镜 "新热点批次" 01
python -X utf8 矩阵制作.py 渲染 "新热点批次" 01
python -X utf8 矩阵制作.py 交付 "新热点批次" 01
python -X utf8 矩阵制作.py 验片 "新热点批次"
```

5. 单条验收回读实片，查音轨、有无跳字、数字、英文字母、图例、字幕、手机两侧、独立封面。交付含 MP4、3:4 封面、首帧、字幕、发布文案和来源。只有用户明确确认过单条样片，才在整批应用确认的改变。

### 随包复现 AIME

进入仓库根目录，按 [首页命令](../README.md#先跑一条样片) 安装和运行。缺中文字体时把 `HANLIN_CJK_REGULAR`、`HANLIN_CJK_BOLD` 指向本机 CJK 字体文件。没有原工作区也可以运行。可用 `--audio 路径 --timing 路径 --cover 路径 --music plucked` 替换输入，输出目录保持新建。当用作双渠道新题时，请逐项改 `render_aime.py` 中的 `SEQUENCE`、`CAPTION_BREAKS`、页眉、封面、六幕函数和片尾。样板中的日期、金额、渠道和 CTA 均是历史案例值。18 句与各幕触发索引同步修改。字幕时间和口播时间都以干声起点为 0；首帧留出的 0.7 秒在渲染时加一次。`timing.json` 含 `cues[]` 的 `start/end/text/anchors`，可选的 `captions[]` 含 `start/end/text`。新音频或新文案必须重新取时间，源样片和时间表成组留档。

单独复用双渠道渲染器时，先把定稿按语义段合成，按试听后的停顿拼出干声。有字级时间就取每句首字、尾字和关键词时点。只有音频时，用逐词转写或试听定位再填写 `cues` 或 `captions`。时间基准是拼接与提速完成后的干声。矩阵四幕的时间表需整理为本渲染器的数据形状。原工作区 AIME 的 `新版样片/配音重制/百炼/` 中，`百炼配音.py --full` 和 `合成与对轴.py` 分别示范分段请求、回执、拼接和字级定位。两脚本引用历史稿，复用时换掉分段映射和文本模板。

| 失败表现 | 处理 | 恢复点 |
|---|---|---|
| 字幕或时间超界 | 回听该句，修正字级锚点、字幕前后和干声时长 | 重新校验时间表 |
| 画面中文缺字、边缘裁掉 | 改用完整简体中文字库并做手机裁切核对 | 重渲染受影响样片 |
| 段落衔接生硬、句尾听不清 | 恢复有用停顿，拆句分段试听，重做变速后时间 | 从审核通过的口播和干声接着做 |
| 首次转写、渲染或入库反复失败 | 核查真实报错、模型/进程、输入指纹和已产出文件，小范围跑通一次 | 从最后验证成功的素材或批次续跑 |

长任务每 20 分钟报告可核实完成数、当前步骤、实际异常和下一检查点。转写、去品牌提炼、线上入库、线上回读各自计数。真有断点就保留原件指纹、素材 ID、阶段、产物和错误。素材取自用户授权来源，分发、正式上传或发布视频按当次授权执行。
