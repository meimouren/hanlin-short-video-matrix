# 选风格与找素材

有工作区时，打开根目录 `短视频风格预览.html`，里面有 7 条可播放样片和 14 张缩略图。下面的风格名对应预览用途。原视频、转写和模板只从获授权的工作区或共享资料库取用。

## 7 类视频风格

| 风格 | 适合的题材和画面动作 | 实片／换题时替换 |
|---|---|---|
| 真人小圆窗＋知识图解 | 讲座原声，讲条件、关系或例题。画面主区先给问题，再点亮相应条件 | 工作区 `三条样片·封面与配乐.html`。换老师原片、分支、起止原话、圆窗安全区 |
| 步骤图卡与三幕答疑 | 补报、材料选择等短问题，逐步呈现，突出当前步骤 | `讲座正文图卡/一段回答怎么剪完整.mp4`。换问题、例外、步骤与动作 |
| 实景与资料推镜 | 需要证明场地、通知、邮件或档案中的具体一句 | `2027-USNCO热点-重制版/模板与成片预览.html`。换实景、通知来源和放大区域 |
| 路线、日历与节点流程 | 地点、时间顺序、晋级或报名流程，按顺序揭示 | 同上 USNCO 线路、翻页和提名。换位置、日期、节点、路径与锚点 |
| 官网操作与字段演示 | 家长需找按钮、表单或选身份字段，光标跟随正确步骤 | 同上 USNCO 官网和表单。换真实网页截图、字段、坐标和操作顺序 |
| 错题批注与限时训练图 | 备考阶段、作答策略和限制，批注对应当前错误 | 同上 USNCO 错题与考程。换错误类型、题目、时限、适用阶段 |
| 双渠道同屏对照 | 同一赛事的两种报名口径并排展示，统一字段、刻度和命名 | [AIME 六幕及独立封面](https://data.hanlin.com/#library/cases/hanlin-aime-two-channel-animation-20261127)。换赛事、渠道、时间、费用、状态和 CTA |

## 14 款独立封面

| 款型 | 题材适配与应替换的部分 |
|---|---|
| 荧光贴纸提问 | 老师答一条高频问题。换真实人像、主问题和贴纸关键词 |
| 白板三分支 | 涉及三个条件或路径。换人物、板书分支和课堂材料 |
| 报刊票签净版 | 政策、时间或报名票签。换人物与标题、票签标签及原始材料 |
| 校园杂志索引 | 经验、校园或阶段规划。换人物、相关校园和索引 |
| 蓝白描边问答 | 明确一问一答的课堂内容。换人物、问句和可读关键词 |
| 深蓝在线课堂 | 学科经验和课程答疑。换真实授课背景、人物及题目 |
| 真人课堂便签 | 考前提醒或容易漏的条件。换老师、道具和便签 |
| 冬季课堂换装 | 季节节点、冬季讲座。用授权老师原照，换适合主题的服装或环境参考 |
| 资料袋摄影 | 材料清单、报名或资料拆解。换真实文件和标签 |
| 校园路线图 | 考点、校园位置、报名路径。换节点、线路、图例 |
| 大字提问 | 一句可讲清的高频问题。换标题及小字条件 |
| 家长问答气泡 | 一问一答、报名条件。换问句、关键答案与能核实的图示 |
| 缺科拼块 | 已排项目与还缺一项。换缺口实体、科目与状态 |
| AIME 蓝红双路线 | 两渠道并列。换赛事、主问题、渠道标签、真实路线含义 |

各封面以现有账号参考馆为主，文件入口为工作区 `工作流样片/AP封面重剪/新版与封面参考馆.html`。装载到目标账号时提供实际 Logo 和当期正文信息，参考样式按主题重排。保留原例、最终独立封面和第 0 帧三项核对记录。
