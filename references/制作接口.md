# 批次字段与动效函数

本页记录 2027-USNCO热点-重制版 的历史矩阵接口。新热点默认走[百炼 1.1 倍配音和对轴入口](接手手册.md#c-热点直接配音和纯动画)。

| 文件 | 数据接口 |
|---|---|
| 批次索引.json | 赛事全称、赛季、整理日期、受众、官方来源数组（名称/地址）、本期说明、素材说明、账号动效、已通过样片配音签名。日期使用实际核实日期。新建批次默认写入「视频号单侧留白像素」124；抖音每侧 24 px。 |
| 本期内容.json | 每条依次为两位编号、平台、账号、历史分类、封面标题、发布文案、四个分镜。每个分镜依次为画面标题、场景名称、关键信息、口播全文。第四段明确福利与领取动作。 |
| 新版分镜.json | 同一编号、当期风格名、阿里云音色、给音色的自然口语指令，再跟四段口播。用竖线分隔短字幕；去掉竖线后的文字应与对应分镜的口播全文一致。兼容本期各账号的音色可参看本期文件。 |
| 素材/ | 用户图、官网截图、已有素材库、翰林原版标识、钢琴采样。用当期核实的文件替换案例素材，在批次索引中注明。 |
| 本期配音/编号/ | narration.wav 为原声，time.json 为原始语速下的短句时间，mix.wav 为加速口播和原速钢琴的立体声混音。仅改画面时直接复用这三项。 |

一条分镜行的局部示例：口播短句为「提交成功，|只是交上了报名表。」时，全文为「提交成功，只是交上了报名表。」。场景动作可用 `moment(1,"提交成功")` 取第二段的实际起句时刻。调整措辞时同步修改触发词。

| 案例入口 | 可以借用的动作 |
|---|---|
| 六账号动效.js / fieldFilm | 取景框、快门、实拍素材横向切换 |
| 参考片动效.js / archiveOpen 至 archiveEnd | 前后景照片视差、原文局部推近、关键条件划线 |
| 六账号动效.js / transit | 折线路径、城市节点、暂定提示、行程票面 |
| 参考片动效.js / dateOpen 至 dateEnd | 翻页铰链、按口播逐日翻牌、赛程截图划重点 |
| 六账号动效.js / inbox | 开信封、回执和确认状态衔接 |
| 六账号动效.js / tutorial | 官网截图裁切、光标跟点、原文放大、提交操作 |
| 六账号动效.js / school | 字段并列、填写归位、先区分身份与所在地 |
| 六账号动效.js / nomination | 按次序点亮节点、连线推进、通知事项核对 |

音效与动态图形应对应具体信息。使用原图时保持图像比例。技术接口以 540×960 的逻辑坐标绘制，以两倍像素输出。四段镜头的起点来自 `time.json`。封面复用已完成构图的开场镜头，前 21 帧冻结。正式首帧与发布封面来自同一个 MP4。

组织新一期时，更新 `channels` 的账号配色和 `newScenes` 的函数映射；按当期问题编写或调整每个函数的片头、答案、注意事项、领取动作、原图、口播锚点。所有现场文字、年份、账号与素材都需与新批次一致。02/04 在当前案例另有已认可的样片路径；为这两个编号注册新函数即可使用新的镜头设计。

修改四段口播后运行「配音」，再从「分镜」到「验片」。仅改动效时运行「分镜」「渲染」「交付」「验片」。仅改发布文案时更新文案输入，然后运行「预览页」同步账号目录的发布文案和整个汇总页。表单截图或报名平台更新时应重新截取并校准点击坐标。
