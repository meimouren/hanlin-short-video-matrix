# 用户规则与验收表

下表在接手、提样片和交付时核对。每项的证据写实际文件、时间点、读音或数据回执。

| 用户要求 | 执行动作 | 验收证据 |
|---|---|---|
| 优先复用已有技能 | 做录播先走真实原声剪辑，热点复用项目的事实、配音、动效和封面能力。先看工作区已有案例 | 可运行入口、样片和所用模板 |
| 先理解口播 | 先提完整口播、按语义通读，再看画面和时间码 | 问题、结论、例子、前提和原话时间 |
| 讲座优先于老师，没课件也能开始 | 用原片确认身份，完整转写后给 3–5 题，选一条剪真实原声 | 源指纹、时间码、候选单和原声净剪 |
| 人物小圆窗，知识占主体 | 主题、字幕、人像和校园素材按场景排；圆窗放在不压信息的位置 | 两个以上实片时点看布局变化 |
| 动画真正解释知识 | 画关系、适用条件、判断路径、对照刻度或步骤，讲到哪一步才动作 | 口播短句与对应的动作、图表逐一对照 |
| 参考真实样片 | 从获认可的真人和无人物案例选画面结构，按当期事实换材料 | 风格类型、案例、适用原因与替换项 |
| 明亮配色 | 默认主背景 `#FFFFFF`、主双色翰林蓝 `#156BB1` / 战绩红 `#A41034`、浅底 `#E2F3FF` / `#FFEDF2`、高亮 `#1681D4` / `#CE2755`、文字 `#102E4B` / `#395872` | 手机下标题可读，颜色还配文字或形状；无 124px 侧边溢光 |
| 封面独立做 | 各条单独生成 3:4 独立封面；AI 生成图左上角留白后，用 `extract_transparent_logo` + `stamp_logo_on_cover` 精准贴合官方商标；真实人物用对应账号授权近照并核对无错字 | 独立 PNG、首 21 帧静止（diff < 1.1）和手机缩略图 |
| 热点无真人也能做 | 纯动画正文配无人物封面。如指定 IP 且有授权音色，可只用其配音 | 片中画面、封面、配音记录 |
| 像顾问说话 | 按[口播去机械化与润色规范](口播去机械化与润色规范.md)编写：口播与发布正文分写，一句交代一件事，单句 ≤ 22 字，去公文词和编号排比，同批尾句不雷同；数字、时刻、英文读法和停顿预标 | 原稿与实际音轨里的 A-M-C、A-I-M-E、日期及金额；`制作工具/口播体检.py` 检查记录 |
| 同主题全量语料 | 从标题、笔记和口播全文联查所有相关素材，逐条复核，待转写后补审 | 命中总数、已读数、待补数、采用/排除依据 |
| 全量转写与入库去品牌 | 每条各记文件、转写、净知识、线上回读状态；知识库正文剔除第三方品牌、账号、广告和导流，只留实质方法；案例依据留授权位置 | 已转写数、去品牌待审数、线上验证数，原片指纹和断点 |
| 内容与渠道事实要对齐 | 核实原通知、地区、渠道、时刻、币种、暂定项。两边用同字段和同时间刻度比较 | 逐字段来源、范围、核实日期和画面 |
| 字清、音色有起伏 | 新热点默认阿里云百炼 `qwen-audio-3.0-tts-plus`，先试问句和提醒，复听咬字和重音。AIME 成片选用系统男声龙安鲁风 | 实际模型、音色及重点句试听 |
| 配音 1.1 倍 | 新热点 AI 配音按成片人声 1.1 倍执行，干声保音高且只变速一次，重算字幕和动画。老师录播保留原声节奏，背景音乐原速 | 1.1 倍参数、最终音轨和对齐后的字幕 |
| 配乐轻快，小声 | 试听至少两种不同编配，保证口播优先，配乐按原速。AIME 验收例 114 BPM 木琴，人声与 BGM 平均约差 21 dB | 试听、混音记录、手机回听 |
| 平台版式和标题 | 竖屏 1080×1920、30 fps，首 21 帧静置；新视频号左右 124 px、抖音 24 px，已认可批次用其专用参数；单行字幕，平台正文标签含 #翰林国际教育 | 手机裁切、首帧、实片字幕、账号和发布文案 |
| 一个福利一个动作 | 让口播、片尾、正文指向同一福利和领取动作 | 三处文字和实际读法一致 |
| 先看一条再批量 | 样片确认后将获认可的修改应用到同批，交付和发布按实际授权 | 确认记录、文件或发布回执分别保存 |
| 避免长时间卡住 | 每 20 分钟报告实际进度，卡住约 5 分钟报告完成项和等待点。逐条检查点恢复，重复报错时先查真实异常再验证一条 | 最近完成项、异常、已回读的恢复点 |
| 分维度做知识库 | 在封面、标题、剪辑、文案、设计分别写观察证据、复用步骤和要换的要素 | 五维可检索，留案例编号和入库回读 |
