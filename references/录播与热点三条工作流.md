# 录播与热点制作入口

适用于给家长看的讲解、报名问答和课程录播。真人 IP 动态小圆窗升级规范与独立命令见 [真人 IP 录播切片工作流](真人IP录播切片工作流.md)。在私有工作区使用时，人读指南见根目录《短视频三条制作工作流.html》，视觉参考入口见 `工作流样片/AP封面重剪/新版与封面参考馆.html`。

## 用户认可的两种讲解正文风格

内容主导的真人讲解参考 `工作区参考视频/13440144505962411.mp4`：先通读参考片完整口播，按问题、论点、证据、转折和结论理解全文，再逐段对照画面承担的讲解功能。把这个方法应用到本条内容，给老师留真人小圆窗，用主画面画出观众需要理解的过程与关系。制作时再用原声时间码定位。

2026-11-26 用户选定以下讲解参考。根据老师实际讲述的内容选择样式，并保留讲座原声。

- **真人与图解同屏**（工作区样片 `参考视频/第四类大猩猩.mp4`，横屏，约 13 分 04 秒）。开场左侧老师出镜，右侧以「人体编程」和图示点题。约 2:52 老师缩至左下，画面展开四个问题；约 9:24 三张卡片列出「读、写、调试」，强调框落在当前讲解项。原片无课件时可将老师确实说过的概念做成对照图。转竖屏时重新安排人像和图解，核看小字与表情。
- **步骤图卡**（工作区样片 `参考视频/mmexport1795666313010.mp4`，竖屏，约 53 秒）。浅色网格底、深字和黄色强调，配有小人物形象。约 0:12、0:20、0:29 依次展示「01 装上技能」「02 丢进去」「03 等着就行」。顶部标出进度，中部图卡随步骤变化，下方保留短字幕。适合原话有明确流程的选段。
- 样片验收时挑一句老师原话，对照该时刻的画面重点，并在手机尺寸下检查图示、字幕与人像是否读得清。


### 按本条题材选择配色和版式

2026-11-26 用户认可工作区 `工作流样片/讲座正文图卡/一段回答怎么剪完整.mp4` 的改进。第一幕的手写场景引出家长问题，第二幕用两张科目签并列“宏观已报”和“微观未排考”，第三幕用黄色答复单收束。新版的深蓝与黄服务于这个例子；新主题从本期内容、账号和可用素材重新确定颜色与构图。

编导在候选选题旁写一句视觉设想，说明观众要看懂哪一处、用什么画面表达；选中试剪的一条再定主色、强调色和切换时刻。同场讲座中相近的小节可沿用同一视觉风格，以稳定的字幕和品牌位置串联。选用颜色时同时用文字、位置或符号区分含义。

讲解视频与独立封面优先使用明亮配色。没有合适题材配色时使用白底、翰林蓝 `#156BB1`、战绩红 `#A41034`。大面积铺色用较亮的同色系，标题与正文确保手机缩小后仍然可读。独立封面选对应账号原例，按 3:4 整图生成，并为 9:16 视频单独适配首帧。
- 比较两本教材时，可以从真实书封取色，让两本书按相同尺度并列，只在老师讲到难度或适用基础时放大对应位置。
- 解释数学推理时，可以用暖白板面、墨色笔迹，单一亮色跟随当下推到的那一步；讲报名日期时，则以日期轴或日历呈现先后，把强调色留给关键节点。
- 老师讲经历时，可以从现场光线和服装取色，保留人像和自然停顿，提到的关键一句进入留白处。

剪辑和验收从实际音轨中各取一句，对照手机尺寸的成片，检查当句的主体、强调与条件是否容易辨认。

## 录播 → 短视频

讲座依次保存整场带时间码的整理文案、由全文选出的段落、按起止原话剪出的原声净素材、由该素材完成的首条样片。生成定稿封面和正文设计从净素材核对通过后开始；候选题中可留一句视觉设想。

1. 在新批次中保存待剪素材位置、老师提供的课件或原始通知、用户指定的模板、账号和目标平台。录播转写与剪辑均在本地进行。
2. 独立技能包可执行 `python -B -X utf8 scripts/transcribe_lecture.py 原片.mp4 工作目录 --terms "中英文赛事名、课程名"`；在私有工作区根目录可执行 `python -X utf8 制作工具/录播转写.py 原片.mp4 工作目录 --术语 "中英文赛事名、课程名"`。输出包含原片指纹、逐词时间及静默/删段线索（私有工作区 `制作工具/录播转写.py` 另调用同级技能 `video-editing-skill` 探测剪点）。建议在环境中安装 `faster-whisper==1.2.1` 运行。默认可选本地模型目录 `.cache/hanlin-video/faster-whisper-small`（或由脚本按 `small` 自动下载）。
3. 通读转写，再选能独立讲完的家长问题。为每条写出明确的答案和标题，保存“原片第几秒讲到哪一句、此刻该看什么”。保留条件、数字、例外和真实老师的语气。用原声或课件校订人名、英语、赛事缩写、金额和日期。
4. 从已有素材库并排看同题材、业务确认获客、高赞及更多账号的视觉原例。先缩小看清主标题，再决定人物、板书、教材或报名资料应占多大。把真实当期材料放进版式。首帧和列表封面单独检查。既有案例图用于参考。
   本项目的封面交给子智能体调用 OpenAI Images 2.6 整图生成。将校对过的标题、需要上图的文字、官方 Logo 原图与视觉参考一并交给模型，直接生成带字的完整成品；取消代码绘图、拼图和后期叠字。回看标题、账号、品牌字形与手机缩略图，发现错字时用模型定点修正。交付模型原图，按实际回执记录可核实的版本信息。
   用户确认「金牌数学竞赛庄博士」和「北大学长聊数学」是自有账号，两位老师的出镜原图可直接作为人物素材。用户另给真人照片时，用指定照片作为人物依据；用同账号原视频对照五官、眼镜、神态、授课场景及标题与人像的比例。将人物与所属账号对应，选与当期主题相关的道具和背景。
5. 写选题单，使用与转写相同的 sha256。“作品”数组每条有标题、封面（分行数组）、账号、平台、片段。每段“起”和“止”是源视频绝对秒数，字幕可写为 [[起,止,"校订短句"]]，取景可写为 [左,上,宽,高] 的归一化值。使用当期设计时填写“设计封面”和“正文底图”（1080×1920 PNG/JPG，可用相对选题单的路径）及“原片画框”（竖屏画布内的像素 [左,上,宽,高]）。基础版式用于粗剪核时。最终版按本次素材和封面方向具体排版；原片画框保留画面比例。
6. 执行 `python -X utf8 制作工具/录播拆条.py 工作目录/原片转写.json 工作目录/选题单.json 新交付目录`。输出每条的成片、首帧、字幕和时间映射。看实片首帧、口型与字幕、课件字、裁切边缘和最后一句。单条改版样片通过后再套用到其余账号。

## 热点 → 老师录制稿 → 回剪

核对当期官方来源与适用范围，给每条设置一个家长问题。使用项目“新建”建立独立批次，然后填写制作模板中的本期内容、新版分镜、批次索引，保持两份语音文本逐段一致。根目录命令 `python -X utf8 矩阵制作.py 老师录制稿 批次名 01` 导出可照读的 HTML；出镜提词、发布文案与分镜按用途展示。成片二次引用这位老师的实际录音时，重新转写和对齐时间。

## 热点 → 配音版

沿用同批核实的事实和口播底稿。新热点默认用阿里云百炼 `qwen-audio-3.0-tts-plus` 合成，成片人声 1.1 倍，从最终干声对齐字幕和动效。使用与该音轨、时间表匹配的渲染入口。新题材需替换样板里的旧赛事素材、说明、动作锚点与福利，按当前录音调整动效；先做一个账号的样片。核对 0 秒、第一次出现答案和片尾的实际视频，完成后提供本地播放、列表封面、发布文案。制作、发布各依当次用户请求执行。

### AIME 两渠道纯动画

适用于同一赛事的两个报名渠道或地区口径。工作区验收示例 `工作流样片/AIME-2027两渠道热点-于老师版/新版样片/配音重制/百炼样片-1.1倍/AIME-纯动画样片.mp4` 及其 `AIME视觉动效升级样片对照.html`，独立技能仓可直接运行 `scripts/render_aime_canvas.py` 复现升级版动效，共享资产见 [资料库案例](https://data.hanlin.com/#library/cases/hanlin-aime-two-channel-animation-20261127)。

1. 先逐渠道核对当期考点入口、选点日期、开考和结束时刻、作答规则、币种、费用及状态。由「先查原报名渠道」进入两列事实。预计和暂定直接贴在对应项。
2. 画面按开场、考点分支、共同刻度的时间对照、适用渠道的分段作答、费用并列、片尾汇总推进。分支在整条片中用一致的名称和颜色。独立封面用无人物双路线，9:16 视频首帧单独适配，视频号版心两侧各 124 px，首 21 帧静置。
3. 本例经试听采用百炼 `qwen-audio-3.0-tts-plus` 系统男声龙安鲁风。先试开场问句、接送时间和 A-I-M-E，再按语义段设置语气并合成，取字级时间戳。AIME 定版干声已做 1.1 倍保音高处理，此参数也是新热点默认值。新合成的原速干声只提速一次，对应时间点除以 1.1 后再加首帧停留。首帧停留时间和配乐节拍单独管理。
4. 抽查最终 MP4 的开头、各渠道时段、交卷条件、费用和片尾。语音识别复核数字和用语，实际试听决定语气、咬字和语速。该样片实测 53.83 秒、18 个口播锚点、25 行字幕、114 BPM 木琴，背景音乐比活跃人声低约 21 dB。

脚本在示例的 `新版样片/制作新版.py`。执行 `python -X utf8 制作新版.py --audio 新干声.wav --timing time.json --cover 独立封面.png --output 新目录` 可从同源素材渲染本例。重剪用现有 `百炼样片-1.1倍` 的干声与时间表。换题材时将六幕分镜和触发语句替换为本期内容，重新生成时间表。配音调用记录和试音版本分别在工程中留档。
