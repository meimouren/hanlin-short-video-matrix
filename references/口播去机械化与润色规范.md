# 口播去机械化与润色规范

面向家长制作短视频时，口播稿是**给耳朵听的微信语音**，不是给眼睛看的公文或图文。本文总结本项目实测暴露的 AI 机械腔成因，并给出可落地的写作与自检红线。

## 一、先听后写，两步成稿（禁止照搬发布正文）

1. **第一步只列事实与语料节奏**：先写出当期核实的日期、数字、条件与出处；若在私有工作区运行，可用 `python -X utf8 "小红书账号归档/口播语料与风格库/更新口播库.py" --关键词 ... --全量` 检索同题材真实口播，并参考工作区 `小红书账号归档/口播语料与风格库/风格库.json` 中的 8 种开场与切段节奏。
2. **第二步合上公文，发一条 40 秒语音**：假想对面就是一位正在问孩子的家长，把第一步列出的事实按“先接住问题 → 直接给判断 → 补最容易漏的 1–2 个条件 → 自然过渡到一项福利”重新说一遍。
3. **口播稿与发布正文必须分写**：发布正文需要信息完整、方便家长截图收藏；口播稿要留停顿、短句、换气口和口语连接词。**严禁直接复制发布正文去配音**（例如 `2027-AP校外补报-Gemini版` 多条存在口播与正文几乎逐字一致的问题）。

## 二、书面公文词与 AI 套话黑名单

口播里出现书面虚词或公文连词，一开口就像机器念通知。写完后逐词替换：

| 常见 AI 书面腔 / 公文词 | 真实顾问口语替换 |
|---|---|
| 均暂定 / 仍待定 | 都还没定 / 还没敲定 / 目前还写着待定 |
| 均需 / 须 / 必须于……前 | 都得先 / 一定要赶在……前 |
| 拟赴 / 可赴考城市 | 准备去的 / 能过去考的城市 |
| 综上所述 / 值得注意的是 / 此外 / 另一方面 | 说白了 / 这里最容易漏 / 还有一点 |
| 进行核对 / 予以确认 / 具备资格 | 对一下 / 问清楚 / 够不够条件 |
| 按……通知执行 / 相关事宜 | 看……发的最新通知 / 这些事儿 |
| 十二月十五日 / 二月七日（口播日期） | 十二月十五号 / 二月七号 |
| 首先……其次……最后…… / 第一种……第二种……第三种…… | 用“一种是……还有一种……”“先看……再看……”打断编号感 |

**正反对照（本项目实测）**：
- 机械版：`晋级美国数学邀请赛（AIME）后，先确认你当时从哪儿报的 AMC。预计十二月十五日可选线下考点。线下机考和三百五十元报名费，目前都暂定。`
- 定版口语（`AIME` 认可版）：`孩子从 AMC 10 或 12 晋级到 AIME 了，这次去哪儿考？您先翻一下当时报名的记录，考点找原报名渠道查。AMC-China 报的，预计十二月十五号能选线下考点。`

## 三、句长、呼吸感与动作连接红线

1. **单口气分句 ≤ 22 字**：按标点或字幕切分符 `|` 切分，每段不超过 22 个有效字词（中文字 + 英文数字词）。超过即拆句，禁止把三四层定语塞进一个长句。
   - 机械长句：`大学理事会给各考点提交春季课程考试订单、调整秋季订单的截止日`
   - 拆句口语：`三月十二号，是官方给各考点报订单的截止日，/ 不是留给家长的最后一天。`
2. **打破等长排比**：禁止连续 3 句字数相近、主谓结构完全一样的“AI 三连句”。善用短问句、生活动作或反直觉提醒切开节奏（例如：`“那么 80 小时够干嘛呢？我拆给你看。”` `“先别直接拿 360 美元乘二。”`）。
3. **禁止纯名词清单砸信息**：不要连续堆无主语短句（如 `两轮都要去指定考点。现场监考，在线答题。`），要带出说话人和动作（`两轮都得去指定考点考，现场有监考，上机答题。`）。

## 四、10 账号说话人设与尾句禁重

同批 10 个账号不能听起来像同一个人换了 10 套皮肤读稿：

| 账号方向 | 推荐说话口吻与句式重心 |
|---|---|
| `01 抖音 · 翰林名师讲堂` | 节奏紧凑、先抛反常识结论或快问快答，少铺垫直接给动作 |
| `02 视频号 · 国际竞赛汪老师` | 长辈式/班主任式耐心口吻，多用“您、咱们”，先安抚再一条条拆 |
| `03 翰林国际竞赛培训` / `04 备考室` | 先给整体时间线或城市路径，把“哪天前干嘛”落到具体日期动作上 |
| `05 翰林培训王老师` | 结合日常学习习惯和复盘动作，用“比如孩子昨天刚……”举例 |
| `06 翰林竞赛小助手` | 实操指路口吻，“打开页面先找哪一行、点哪个按钮”，像在旁边指屏幕 |
| `07 翰林名师讲堂（视频号）` | 挑容易填错或理解偏差的细节做对照提醒 |
| `08 精讲` / `09 辅导` / `10 课程` | 分别侧重规则拆解、错因举例、分阶段训练节奏，不互相撞例子 |

**片尾福利禁重硬规则**：
- **严禁同批 3 条以上使用同一套结尾句式**（例如 `2027-USNCO热点-重制版` 多次重复 `“……后，想……？可以后台私信我们，免费领取……”`）。
- 同一批次应混用不同自然接话方式（每条只留一种福利和一种领取动作）：
  1. 动作接话：`“考点定下来了，想提前摸底题型的，后台发我「真题」两个字，我把往年试卷发您。”`
  2. 问题承接：`“真不确定孩子现在卡在哪块，评论区打个「测试」，约一次免费水平摸底。”`
  3. 清单顺接：`“想省事儿，想要两边的对照表，直接私信我 A-I-M-E 就行。”`
  4. 备考顺延：`“报完名不知道从哪本教材下手？评论区回个「书单」，先领一份备赛书单对照看。”`
  5. 提醒收尾：`“别光看时间表，把家门口能去的城市发来，私信我帮您核对这一轮的余位。”`

## 五、交稿与配音前 5 项硬自检

定稿前先运行自动检查工具（对独立技能包及历史批次回审均适用）：

```powershell
# 独立技能包通用命令
python -B -X utf8 scripts/check_copy.py "稿件或字幕路径"
# 私有工作区命令
python -B -X utf8 制作工具/口播体检.py "批次名或稿件路径"
```

1. **无公文腔**：无 `均暂定 / 仍待定 / 须 / 拟赴 / 综上所述 / 首先其次最后`，日期念“号”。
2. **无编号排比**：无 `第一种/第二种/第三种` 或连续 3 句等长排比。
3. **单句能一口气念完**：每段分句 ≤ 22 字，括号/书面补充已拆掉或口语化。
4. **口播 ≠ 正文**：口播稿和发布正文分开撰写，不照搬正文长句。
5. **账号口吻与尾句拉开**：同批不同账号结尾过渡有明显变化，不套用同一套尾句模板。
